# Генератор таблиц погрешностей ИК АИИС КУЭ (Windows 10/11)

Профессиональное приложение для расчета и автоматической генерации таблиц метрологических погрешностей измерительных каналов (ИК) систем коммерческого учета электроэнергии (АИИС КУЭ) в нормальных и рабочих условиях эксплуатации.

Расчеты полностью соответствуют нормативной базе:
- **ГОСТ Р 8.596-2002** «Метрологическое обеспечение измерительных систем. Основные положения»
- **МИ 3000-2006** «ГСИ. Системы автоматизированные информационно-измерительные коммерческого учета электрической энергии. Типовая методика измерений»
- **ГОСТ 7746-2001 / ГОСТ 7746-2015** (Трансформаторы тока)
- **ГОСТ 1983-2001 / ГОСТ 1983-2015** (Трансформаторы напряжения)
- **ГОСТ 31819.21, ГОСТ 31819.22, ГОСТ 31819.23** (Счетчики электрической энергии)

---

## 🚀 Возможности программы

1. **Любые сочетания оборудования:**
   - **Трансформаторы тока (ТТ):** класс точности `0.2S`, `0.5S`, `0.2`, `0.5`, либо прямое включение (`Без ТТ`);
   - **Трансформаторы напряжения (ТН):** класс точности `0.2`, `0.5`, либо прямое/низковольтное включение (`Без ТН`);
   - **Счетчики электроэнергии:** `0.2S / 0.5`, `0.5S / 1.0`, `0.5S / 0.5`, `1.0 / 1.0`, `1.0 / 2.0`, `0.2S / 0.2S` (СЭТ-4ТМ, Меркурий 230/234, ТЕ2000, РИМ и др.);
   - **Температурные диапазоны:** готовые пресеты (шкаф $+10 \dots +35 ^\circ\text{C}$, паспорт-формуляр $0 \dots +40 ^\circ\text{C}$, испытания $-3 \dots +43 ^\circ\text{C}$, улица $-40 \dots +55 ^\circ\text{C}$), либо ввод любого произвольного значения $\Delta t$;
   - **Потери напряжения в линии связи ТН–счетчик ($\delta_L$):** регулируемое значение (по умолчанию $0,25\%$, обнуляется для каналов без ТН);
   - **Внешнее магнитное поле ($\delta_{\text{ми}}$):**
     - **По ГОСТ 31819 (по умолчанию):** нормируется при номинальном токе $I_{\text{ном}} (100\%)$ и $\cos \varphi = 1.0$: $\pm 0,5\%$ (для 0,2S), $\pm 1,0\%$ (для 0,5S), $\pm 2,0\%$ (для 1,0);
     - **Во всех точках диапазона:** для счетчиков с постоянным нормированием магнитного влияния (напр. РИМ 384.02);
     - **Пользовательское значение:** ввод произвольного значения $\delta_{\text{ми}}$ в %;
     - **Не учитывать (н/н во всех точках):** отключение учета.

2. **Два формата генерируемых таблиц:**
   - **Сводная таблица (15 граф):** канонический формат для отчетов об испытаниях (Таблица 12) и проектов Описания типа (ОТ);
   - **Полная таблица (29 граф по МИ 3000):** содержит все детальные составляющие погрешности ($\delta_i, \theta_i, \delta_u, \theta_u, \delta_\theta, \delta_L, \delta_{\text{с.о}}, \delta_{ct}, \delta_{cU}, \delta_{cf}, \delta_{\text{ми}}, \delta_{W\text{ осн}}, \delta_{W\text{ раб}}$).

3. **Экспорт и интеграция с Microsoft Office:**
   - 📋 **Копирование в буфер обмена (TSV):** позволяет одним кликом скопировать таблицу и сразу вставить её через `Ctrl+V` в Excel или Word;
   - 📊 **Экспорт в Microsoft Excel (.xlsx):** профессионально оформленные таблицы с заливкой шапки, центровкой данных, автоподбором ширины столбцов и закреплением областей;
   - 📝 **Экспорт в Microsoft Word (.docx):** оформление по ГОСТ 7.0.97, альбомная ориентация для 29-колоночных таблиц, шрифт Times New Roman, повторяющиеся заголовки на разрывах страниц (`tblHeader`).

4. **Пакетный расчет:**
   - Возможность одним нажатием рассчитать сразу все 8 типовых групп проекта АИИС КУЭ (высоковольтные вводы, РУ-10 кВ, прямое включение 0,4 кВ, каналы 0,4 кВ с ТТ без ТН и др.).

## 📦 Быстрый запуск

### Вариант 1. Запуск через пакетный файл (в 1 клик)
Просто запустите файл:
```bat
run.bat
```

### Вариант 2. Запуск через Python
```bash
pip install -r requirements.txt
python app.py
```

### Вариант 3. Использование через командную строку (CLI)
```bash
# Расчет с нормативом ГОСТ для δми (по умолчанию):
python app.py --cli --tt 0.5S --th 0.5 --meter "0.2S / 0.5" --dt 20 --out "Погрешности.xlsx"

# Учет магнитного поля во всех точках (режим all):
python app.py --cli --tt 0.5S --th 0.5 --meter "0.2S / 0.5" --mag all --out "Погрешности_магнит.xlsx"

# Пакетный расчет всех 8 типовых групп проекта:
python app.py --cli --all-groups --out "Сводный_отчет_все_группы.xlsx"
```

## 📐 Математический аппарат расчета

### 1. Основная погрешность ИК ($\delta_{W\text{ осн}}$)
$$\delta_{W\text{ осн}} = \pm 1,1 \cdot \sqrt{\delta_i^2 + \delta_u^2 + \delta_\theta^2 + \delta_L^2 + \delta_{\text{с.о}}^2}$$
*(Для каналов прямого включения без ТТ и ТН: $\delta_{W\text{ осн}} = \pm 1,1 \cdot \delta_{\text{с.о}}$)*

### 2. Угловая погрешность измерительного тракта ($\delta_\theta$)
- Для активной электроэнергии:
  $$\delta_\theta = 0,029 \cdot \sqrt{\theta_i^2 + \theta_u^2} \cdot \tan \varphi$$
- Для реактивной электроэнергии:
  $$\delta_\theta = 0,029 \cdot \sqrt{\theta_i^2 + \theta_u^2} \cdot \cot \varphi$$

### 3. Рабочая погрешность ИК ($\delta_{W\text{ раб}}$)
$$\delta_{W\text{ раб}} = \pm 1,1 \cdot \sqrt{\delta_{W\text{ осн\_без\_1.1}}^2 + \delta_{ct}^2 + \delta_{cU}^2 + \delta_{cf}^2 + \delta_{\text{ми}}^2}$$
где:
- $\delta_{ct} = K_t \cdot \Delta t$ — дополнительная температурная погрешность счетчика;
- $\delta_{cU}$ — погрешность от колебаний напряжения сети ($\pm 10\%$);
- $\delta_{cf}$ — погрешность от отклонения частоты ($\pm 0,4\text{ Гц}$);
- $\delta_{\text{ми}}$ — погрешность от внешнего магнитного поля ($0,5\text{ мТл}$): по ГОСТ 31819 при $I_{\text{ном}}, \cos \varphi = 1$ равна $0,5\%$ (для 0,2S), $1,0\%$ (для 0,5S), $2,0\%$ (для 1,0).
