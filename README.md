# Калькулятор и генератор таблиц погрешностей ИК АИИС КУЭ

[![GitHub Release](https://img.shields.io/github/v/release/komu-to/aiis-kue-error-calc?color=blue&logo=github)](https://github.com/komu-to/aiis-kue-error-calc/releases/latest)

[![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-0078D6?logo=windows)](https://microsoft.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Профессиональный инженерный инструмент для расчета метрологических характеристик и автоматической генерации таблиц погрешностей измерительных каналов (ИК) систем коммерческого и технического учета электроэнергии (АИИС КУЭ / АСТУЭ).

Разработан как для **инженеров-проектировщиков и метрологов** (удобный GUI-интерфейс, экспорт в ГОСТ-форматированные таблицы Word и Excel), так и для **автономных AI-агентов и CI/CD скриптов** (CLI-режим, типизированный Python API, экспорт в TSV/JSON).

---

## 📚 Нормативная база

Все метрологические расчеты строго соответствуют актуальным государственным стандартам РФ:
* **ГОСТ Р 8.596-2002** — «Метрологическое обеспечение измерительных систем. Основные положения»
* **МИ 3000-2006** — «ГСИ. Системы автоматизированные информационно-измерительные коммерческого учета электрической энергии. Типовая методика измерений»
* **ГОСТ 7746-2001 / ГОСТ 7746-2015** — Трансформаторы тока (ТТ)
* **ГОСТ 1983-2001 / ГОСТ 1983-2015** — Трансформаторы напряжения (ТН)
* **ГОСТ 31819.21, ГОСТ 31819.22, ГОСТ 31819.23** — Счетчики активной и реактивной электрической энергии
* **ГОСТ Р 7.0.97-2016** — Требования к оформлению документов и таблиц

## ⚡ Быстрый старт для пользователей (GUI)

1. Скачайте `AIIS_KUE_Error_Calc.exe` (или запустите `run.bat` из клонированного репозитория).
2. Выберите параметры канала:
   * **Номер(а) ИК:** например, `1, 2, 15, 16`
   * **Класс точности ТТ:** `0.2S`, `0.5S`, `0.2`, `0.5` или `Без ТТ` (прямое включение)
   * **Класс точности ТН:** `0.2`, `0.5` или `Без ТН`
   * **Класс точности счетчика:** `0.2S / 0.5`, `0.5S / 1.0`, `1.0 / 2.0` и др.
   * **Температурный диапазон:** быстрые пресеты ($0 \dots +40 ^\circ\text{C}$, $+10 \dots +35 ^\circ\text{C}$, $-3 \dots +43 ^\circ\text{C}$, $-40 \dots +55 ^\circ\text{C}$) или произвольное отклонение $\Delta t$
   * **Потери в кабеле ТН ($\delta_L$):** регулируемое значение (по умолчанию $0,25\%$, обнуляется для прямого включения)
   * **Влияние магнитного поля ($\delta_{\text{ми}}$):**
     * *По ГОСТ 31819 (по умолчанию):* нормируется при $I = 100\%$ и $\cos \varphi = 1.0$ ($0,5\%$ для 0.2S, $1,0\%$ для 0.5S, $2,0\%$ для 1.0, в остальных точках — `н/н`);
     * *Во всех точках диапазона:* для приборов учета с полным нормированием (напр. РИМ 384);
     * *Пользовательское значение:* ввод произвольного $\delta_{\text{ми}}$ в %;
     * *Не учитывать:* `н/н` во всех строках.
3. Нажмите **«🚀 Рассчитать вариант»** или **«📑 Все группы проекта»** (пакетный расчет всех типовых групп).
4. Экспортируйте результат:
   * **📋 Копировать в буфер** (`Ctrl+C`): копирует TSV для мгновенной вставки в любую открытую таблицу Word/Excel;
   * **📊 Экспорт в Excel (.xlsx):** генерирует красиво стилизованную таблицу с центровкой, чередующейся подсветкой строк и автоподбором колонок;
   * **📝 Экспорт в Word (.docx):** формирует документ ГОСТ с альбомной ориентацией, шрифтом Times New Roman и повторением заголовка на каждой странице (`tblHeader`).

> [!TIP]
> При экспорте имя файла формируется автоматически по информативному стандарту:  
> `№каналов-ТТ_ТН_Счетчик_температура.<расширение>`  
> *(Например: `ИК1,2,15,16-ТТ0.2S_ТН0.2_Сч0.2S-0.5_t12C.xlsx`)*

## 🤖 AI Agent & Automation Integration (LLM / CLI / Headless)

Программа полностью адаптирована для вызова AI-агентами (Claude, Gemini, ChatGPT, авто-ботами) и CI/CD скриптами без поднятия дисплея.

### 1. Интерфейс командной строки (CLI)

```bash
python app.py --cli [ПАРАМЕТРЫ]
```

#### Справочник аргументов CLI:

| Флаг | Тип | По умолчанию | Допустимые значения / Описание |
| :--- | :--- | :--- | :--- |
| `--cli` | flag | `False` | Запуск в консольном режиме без открытия окон GUI |
| `--ik` | string | `"1"` | Номер или перечень каналов (напр. `"1, 2, 15, 16"`) |
| `--tt` | string | `"0.5S"` | `"0.2S"`, `"0.5S"`, `"0.2"`, `"0.5"`, `"Без ТТ"` |
| `--th` | string | `"0.5"` | `"0.2"`, `"0.5"`, `"Без ТН"` |
| `--meter` | string | `"0.2S / 0.5"` | `"0.2S / 0.5"`, `"0.5S / 1.0"`, `"0.5S / 0.5"`, `"1.0 / 1.0"`, `"1.0 / 2.0"` |
| `--dt` | float | `20.0` | Предельное отклонение температуры $\Delta t$ от нормальной ($20 ^\circ\text{C}$), в $^\circ\text{C}$ |
| `--dL` | float | `0.25` | Потери напряжения в кабеле ТН-счетчик $\delta_L$, в % |
| `--mag` | choice | `"gost"` | Режим учета поля $\delta_{\text{ми}}$: `gost`, `all_points`, `none`, `custom` |
| `--mag-val`| float | `0.5` | Значение $\delta_{\text{ми}}$ в % (для `--mag custom`) |
| `--all-groups` | flag | `False` | Пакетный расчет всех 8 типовых проектных групп АИИС КУЭ |
| `--mode` | choice | `"full"` | Формат таблицы: `summary` (15 граф) или `full` (29 граф МИ 3000) |
| `--out` | string | `None` | Путь сохранения файла (`.xlsx`, `.docx`, `.tsv`), либо `auto.xlsx` / `auto.docx` |

#### Примеры вызова из терминала / скрипта:

```bash
# 1. Расчет конкретного канала с авто-именованием Excel-файла
python app.py --cli --ik "1, 2, 15, 16" --tt "0.2S" --th "0.2" --meter "0.2S / 0.5" --dt 12 --out auto.xlsx

# 2. Расчет прямого включения 0,4 кВ (без ТТ и ТН) в Word (.docx)
python app.py --cli --ik "23" --tt "Без ТТ" --th "Без ТН" --meter "0.5S / 1.0" --dt 20 --out auto.docx

# 3. Пакетная генерация сводной таблицы всех групп проекта
python app.py --cli --all-groups --dt 20 --out "Все_Группы_Проекта.xlsx"
```

### 2. Прямой программный API для Python (Sub-millisecond)

AI-агенты могут напрямую импортировать вычислительное ядро и генераторы отчетов:

```python
from core import generate_group_table, PRESET_PROJECT_GROUPS
from exporters import export_to_excel, export_to_docx, make_export_filename, get_tsv_text

# Выполнение расчета (возвращает список словарей со всеми 29 графами)
rows = generate_group_table(
    ik_num="1, 2",
    tt_class="0.2S",
    th_class="0.2",
    meter_class="0.2S / 0.5",
    delta_t=12.0,
    delta_L=0.25,
    magnetic_mode="gost"
)

# rows — список из 20 контрольных точек по МИ 3000 (токи 5%, 20%, 100%, 120%; cos φ 0.5 ... 1.0)
print(f"Рассчитано строк: {len(rows)}")
print(f"Точка 100%, cos=1.0: dW_раб(акт) = {rows[15]['dW_rab_act']}%")

# Сохранение в Excel с авто-именем
filename = make_export_filename("1, 2", "0.2S", "0.2", "0.2S / 0.5", delta_t=12.0, ext="xlsx")
export_to_excel(rows, filepath=filename, mode="full", title="Таблица погрешностей ИК 1, 2")
```

#### Схема полей расчетного словаря (`row`):

Каждая строка `Dict[str, Any]` содержит следующие ключи:
* `ik`: Наименование/номер измерительного канала
* `i1`: Значение первичного тока в % от номинального (`5`, `20`, `100`, `120` или `100-120`)
* `cos_phi`: Коэффициент мощности нагрузки (`0,5`, `0,8`, `0,9`, `1,0`)
* `kt_tt`, `kt_th`: Классы точности ТТ и ТН
* `delta_i`, `theta_i`: Погрешности ТТ ($\delta_i$ в %, $\theta_i$ в минутах)
* `delta_u`, `theta_u`: Погрешности ТН ($\delta_u$ в %, $\theta_u$ в минутах)
* `delta_theta_act`, `delta_theta_react`: Угловая погрешность тракта $\delta_\theta$ (акт / реакт) в %
* `delta_L`: Потери напряжения в проводном тракте в %
* `kt_meter_act`, `kt_meter_react`: Классы точности счетчика
* `dco_act`, `dco_react`: Основная погрешность счетчика $\delta_{\text{с.о}}$ в %
* `delta_t`: Отклонение температуры $\Delta t$ в $^\circ\text{C}$
* `dct_act`, `dct_react`: Дополнительная температурная погрешность $\delta_{ct}$ в %
* `dcU_act`, `dcU_react`: Погрешность от отклонения напряжения сети $\delta_{cU}$ в %
* `dcf_act`, `dcf_react`: Погрешность от отклонения частоты сети $\delta_{cf}$ в %
* `dmi_act`, `dmi_react`: Погрешность от внешнего магнитного поля $\delta_{\text{ми}}$ в % (или `"н/н"`)
* `dW_osn_act`, `dW_osn_react`: Итоговая **основная погрешность ИК** $\delta_{W\text{ осн}}$ в %
* `dW_rab_act`, `dW_rab_react`: Итоговая **рабочая погрешность ИК** $\delta_{W\text{ раб}}$ в %

## 📐 Математический аппарат расчета

### 1. Основная погрешность измерительного канала ($\delta_{W\text{ осн}}$)
По МИ 3000 и ГОСТ Р 8.596 доверительные границы относительной погрешности при $P = 0,95$:
$$\delta_{W\text{ осн}} = \pm 1,1 \cdot \sqrt{\delta_i^2 + \delta_u^2 + \delta_\theta^2 + \delta_L^2 + \delta_{\text{с.о}}^2}$$

*(Для каналов прямого включения без ТТ и ТН формула сводится к основной погрешности счетчика: $\delta_{W\text{ осн}} = \pm 1,1 \cdot \delta_{\text{с.о}}$).*

### 2. Угловая погрешность измерительного тракта ($\delta_\theta$)
Возникает из-за сдвига фазовых углов вторичных обмоток ТТ ($\theta_i$) и ТН ($\theta_u$):
* **Для активной энергии:**
  $$\delta_\theta = 0,029 \cdot \sqrt{\theta_i^2 + \theta_u^2} \cdot \tan \varphi$$
* **Для реактивной энергии:**
  $$\delta_\theta = 0,029 \cdot \sqrt{\theta_i^2 + \theta_u^2} \cdot \cot \varphi$$

*(При $\cos \varphi = 1,0$ значение $\tan \varphi = 0$, поэтому $\delta_\theta = 0$).*

### 3. Рабочая (эксплуатационная) погрешность ($\delta_{W\text{ раб}}$)
$$\delta_{W\text{ раб}} = \pm 1,1 \cdot \sqrt{\Sigma_{\text{осн\_квадр}}^2 + \delta_{ct}^2 + \delta_{cU}^2 + \delta_{cf}^2 + \delta_{\text{ми}}^2}$$

где:
* $\delta_{ct} = K_t \cdot \Delta t$ — дополнительная температурная погрешность счетчика ($K_t = 0,03 \dots 0,1\%/^\circ\text{C}$);
* $\delta_{cU}$ — погрешность при колебаниях напряжения сети $\pm 10\%$;
* $\delta_{cf}$ — погрешность при отклонениях частоты промышленной сети $\pm 0,4\text{ Гц}$;
* $\delta_{\text{ми}}$ — погрешность от влияния магнитной индукции $0,5\text{ мТл}$ (по ГОСТ 31819 при $I_{\text{ном}}, \cos \varphi = 1$: $0,5\%$ для кл. 0.2S; $1,0\%$ для кл. 0.5S; $2,0\%$ для кл. 1.0).

## 🛠️ Разработка и локальная сборка

Если вы хотите внести изменения и скомпилировать проект локально:

